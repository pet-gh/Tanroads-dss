DSS Framework — FAHP + TOPSIS
1

Data Collection

PCI, IRI, AADT, maintenance cost estimates, and expert judgments collected from TANROADS field engineers and inspectors across Tanzania's trunk and regional road network.

2

Criteria Weighting — Fuzzy AHP

Five criteria weighted using pairwise comparison: Effectiveness (0.29), Value Addition (0.24), Cost (0.21), Implementation (0.16), Safety (0.10). Consistency Ratio verified within acceptable limits.

3

Decision Matrix Construction

Seven maintenance strategies evaluated against five criteria using triangular fuzzy numbers (l, m, u) to capture uncertainty in expert judgment. Numbers defuzzified and normalized.

4

TOPSIS Ranking

Euclidean distance calculated from Positive Ideal Solution (A⁺) and Negative Ideal Solution (A⁻). Closeness Coefficient CC = S⁻ / (S⁺ + S⁻) determines final ranking.

5

GIS Integration

Road segments mapped spatially using Leaflet.js with OpenStreetMap. Each segment colour-coded by PCI condition. Click any marker to view full DSS recommendation for that segment.

6

Budget Optimization

Available budget allocated across road segments using priority-based, condition-based, or traffic-based strategies. Optimized allocation ensures maximum network performance per TZS spent.

7

PDF Report Export

Full DSS report exported as a printable PDF including rankings, road segment data, budget allocation summary, and recommended maintenance strategies for TANROADS submission.
